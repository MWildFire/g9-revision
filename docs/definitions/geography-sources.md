# Geography definition review

All English and Russian learning definitions are authored paraphrases. A Russian interface does not imply a published Russian quotation: every link declares its source language. English terms are retained where Russian and English school classifications differ. Sources were read at the sections below; unsuccessful access attempts were excluded from the new definition citations. The existing case-study bibliography is retained separately from this term review.

The review covers 97 detailed legacy cards in each language, repeated summary definitions, 40 tectonic glossary entries, extra topics, practice wording and the teaching simulations. The audit distinguishes original definition fields from added explanatory material.

The diagrams are authored SVG teaching models. River-process arrows distinguish the material being eroded. Bradshaw lines show relative tendencies and do not pretend to be measurements. The hydrograph has an explicit rainfall peak, discharge peak and consistent lag; it is not a calibrated forecast. ENSO shows westward winds and changing upwelling without deterministic local flood predictions. Butler’s branches show possible trajectories, with no fixed duration. Existing tectonic diagrams distinguish lithosphere from crust, focus from epicentre, anatomy from hazards, and hazard from risk. Concise social definitions and data categories use comparisons and examples instead of decorative illustrations.
